# Titanic Dataset Analysis

## Experiment 01: Exploring Kaggle & GitHub

### Objective
To explore the Titanic dataset from Kaggle and perform basic Exploratory Data Analysis (EDA) using Python and Pandas.

### Dataset
- Dataset: Titanic - Machine Learning from Disaster
- Source: Kaggle

### Tools Used
- Python
- Pandas
- Google Colab
- GitHub

### Analysis Performed
- Loaded the dataset using Pandas
- Displayed the first 5 rows (`head()`)
- Checked dataset information (`info()`)
- Generated summary statistics (`describe()`)
- Identified missing values (`isnull().sum()`)
